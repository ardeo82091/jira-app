Connect your Jira (one time)

Your widget needs your own Jira login to show your tasks. It only sees what you can see in Jira. The token stays encrypted on this laptop, and you won't be asked again.

  1. Open id.atlassian.com → API tokens → Create API token
  2. Paste it below with your Jira e-mail
Create one at id.atlassian.com → Security → API tokens.

Tip: if the Windows environment variables JIRA_EMAIL (or JIRA_USERNAME) and JIRA_API_TOKEN are set, the widget connects automatically and skips this screen.
